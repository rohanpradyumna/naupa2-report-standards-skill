# naupa2-report-standards

[![skills.sh](https://skills.sh/b/rohanpradyumna/naupa2-report-standards-skill)](https://skills.sh/rohanpradyumna/naupa2-report-standards-skill)

A Claude Code skill: reference and self-audit checklist for generating and
reviewing **NAUPA II** unclaimed-property holder report files (the 625-byte
fixed-width electronic format used to file with U.S. state unclaimed
property administrators), plus the human-readable report/cover-sheet
package that accompanies them.

Use it when building, editing, or reviewing code that produces NAUPA II
output, holder report PDFs, or due-diligence filing packages — or when
auditing an existing NAUPA report generator against the real standard.

## Install

```bash
npx skills add rohanpradyumna/naupa2-report-standards-skill
```

## Contents

- `skills/naupa2-report-standards/SKILL.md` — the skill itself.

See the skill file for the full NAUPA II field layout, name-field
sanitization rules, per-state filing and aggregation rules, current code
tables, and a self-audit checklist.
