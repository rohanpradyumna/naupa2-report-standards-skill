# References

Sources behind `skills/naupa2-report-standards/SKILL.md`, split into what's
bundled/verified here vs. what's cited by name only in the original research
and hasn't been re-fetched or link-verified in this repo.

## Bundled in this repo

- **`NAUPA-Standard-Electronic-File-Format-2019.pdf`** — the official NAUPA
  standard electronic file format specification (11/20/2019 revision),
  fetched from
  [unclaimed.org/wp-content/uploads/NAUPAStandardElectronicFileFormat-11.20.19.pdf](https://unclaimed.org/wp-content/uploads/NAUPAStandardElectronicFileFormat-11.20.19.pdf).
  This is the primary source for the 625-byte record layout, field
  definitions, and code tables in the skill. The skill notes this 2019 PDF
  was cross-checked against the 2025 revision and found word-for-word
  identical except two citation URLs (an ISO country-code link and a
  census.gov NAICS link) — the 2025 PDF itself was not captured here.

## Verified live (URL confirmed reachable, content not re-fetched/archived here)
